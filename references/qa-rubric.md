# 问答评分细则（qa 模式）

配套 `SKILL.md` §9 使用。适用于用户明确要求给**回答、分析、方案、文档**等非代码输出打分的场景。星级总表、Gate 机制、评分纪律与代码模式完全一致，仅五维锚点不同。

工具命令：`python scripts/score.py --mode qa --need N --correct N --security N --maint N --verify N`

## 1. 判定顺序

```
① 确认评的是哪段输出（回答全文 / 某一节）
② 跑问答 Gate：答非所问 → 上限 1；编造事实/伪造引用 → 0
③ 五维各打 0-5，每维附证据（引用原文/指出缺失）
④ 加权 → 原始星级 → min(Gate 上限) = 最终星级
```

## 2. 五维锚点

### 2.1 切题准确（35%）

| 分 | 锚点 |
| --- | --- |
| 5 | 直答问题本身 + 覆盖隐含意图（用户没问但显然需要的前提/坑），无废话 |
| 4 | 直答准确，隐含意图覆盖大部分；有少量无关展开 |
| 3 | 答了主要部分，但夹杂明显跑题、重复铺垫或答非所问的次要内容 |
| 2 | 回答偏移：只沾到问题边缘，或基于对问题的误读展开 |
| 1 | 答非所问 / 严重偏题（自动封顶 1 星） |
| 0 | 与问题无关 |

### 2.2 完整深度（25%）

| 分 | 锚点 |
| --- | --- |
| 5 | 关键分支、例外情况、取舍理由全部覆盖；该提醒的风险有提醒 |
| 4 | 主干完整，缺 1 个非关键例外 |
| 3 | 只给主干结论，缺关键例外或适用条件 |
| 2 | 内容有实质错误，或缺核心部分（问 A 答 B 的子集） |
| 1 | 内容错误或缺失关键部分（自动封顶 1 星） |
| 0 | 空泛套话，无信息量 |

### 2.3 依据可靠（15%）

| 分 | 锚点 |
| --- | --- |
| 5 | 每个结论有出处（引用/文档/可推导的推理链）；不确定处明确标注"不确定"及原因 |
| 4 | 结论基本有依据；个别断言未给来源 |
| 3 | 部分结论无依据，靠"一般来说"撑住 |
| 2 | 大部分结论无依据，混合猜测 |
| 1 | 关键结论编造事实、伪造引用或与给定材料矛盾 |
| 0 | 大面积编造（→ 直接 0 星，命中 Gate） |

### 2.4 结构表达（15%）

| 分 | 锚点 |
| --- | --- |
| 5 | 结论先行、层次清晰、长度与问题复杂度匹配；格式辅助理解（列表/代码块用对地方） |
| 4 | 结构清楚；小瑕疵（标题层级乱、一处格式错误） |
| 3 | 信息全在但堆砌，重点不突出，需要读者自己整理 |
| 2 | 逻辑跳跃、前后矛盾、大段无结构文本 |
| 1 | 混乱到难以从中获取答案 |

### 2.5 可核验（10%）

| 分 | 锚点 |
| --- | --- |
| 5 | 给出可复现的命令/链接/推演步骤，照做能得到同样结论 |
| 4 | 给出关键出处或推演，细节需读者补齐 |
| 3 | 只有结论，不可复核，但未声称验证过 |
| 2 | 说"我验证过/实测过"但没给任何证据 |
| 1 | 声称验证过且给出的"证据"与内容自相矛盾 |
| 0 | 伪造运行结果/伪造引用（→ 直接 0 星，命中 Gate） |

## 3. 评分纪律（问答特有）

1. **证据=引用原文**：扣分时引用回答原句或指出"缺了什么"，不接受"感觉不对"。
2. **"不知道"不扣分**：明确标注的不确定优于自信的编造；编造才重罚。
3. **长度中立**：短而准 > 长而全但注水；注水扣结构分，不扣切题分。
4. **跟随追问**：用户追问指出遗漏后，补全的新回答按新一轮评，旧回答的分不改。
5. **不谄媚**：回答中过度奉承/无原则附和用户错误观点，扣切题准确（未指出错误）与依据可靠各 0.5-1。
